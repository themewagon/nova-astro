# Product

## Register

product

## Users

WebScale designers and developers use the Starter Kit component library while
assembling client websites. They browse section variants, compare isolated
previews, filter a large catalog, search by implementation details, and open a
variant when it is ready for reuse.

## Product Purpose

The library turns the Starter Kit registry into a fast visual decision tool.
Success means a user can understand the catalog state, find the right family,
compare variants, and open a preview without fighting the interface.

## Brand Personality

Focused, editorial, exact. The interface should feel like a well-made internal
design tool, with quiet confidence and enough character to make browsing feel
intentional.

## Anti-references

Avoid dashboard clutter, stacked filter panels, generic pill badges, weak gray
hierarchies, decorative gradients, oversized empty controls, and interfaces
that make every option look equally important.

## Design Principles

1. Put the catalog and its previews first; controls support browsing instead of
   competing with it.
2. Use one clear active state and a restrained neutral vocabulary for inactive
   controls.
3. Create hierarchy through spacing, typography, and grouping before adding
   decoration.
4. Preserve density where it helps comparison, but give every control enough
   room to remain legible and usable.
5. Make responsive behavior structural: controls wrap or scroll, cards remain
   comparable, and no label depends on hover.

## Accessibility & Inclusion

Support keyboard navigation, visible focus states, semantic headings and
labels, readable contrast, reduced motion, lazy previews, and touch-friendly
controls. Search and filters must expose their current state to assistive
technology.
